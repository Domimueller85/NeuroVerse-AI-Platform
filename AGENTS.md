- This repository currently contains documentation only.

## Working in this repository

- Keep changes focused on documentation.
- Do not describe proposed functionality, security controls, compliance measures, setup steps, or APIs as implemented without code and verifiable evidence.
- Do not commit credentials, personal data, or vulnerability details.
- Report security concerns through GitHub private vulnerability reporting when enabled; otherwise contact the repository owner privately. See `SECURITY.md`.
- Preserve third-party notices and license terms when adding third-party material.
- Do not resolve or characterize the conflicting terms in `LICENSE` and `LICENSE.md`; the project owner must resolve them with qualified legal counsel.
