# Contributing

This repository currently contains project documentation only; there is no
application code or automated test suite to develop against. Contributions are
not currently being solicited.

Before accepting outside contributions, the project owner should define the
contribution process and resolve the conflicting terms in [`LICENSE`](./LICENSE)
and [`LICENSE.md`](./LICENSE.md) with qualified legal counsel. Repository
access alone should not be described here as acceptance of a license, NDA, or
other legal agreement.

When contributions are opened, this guide should be updated with verified
development setup, formatting, testing, and pull request instructions.
